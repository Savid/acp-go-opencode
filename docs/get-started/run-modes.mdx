## Standalone subprocess

Install or run the command when an editor or ACP host needs an executable:

```sh
go install github.com/savid/acp-go-opencode/cmd/acp-go-opencode@latest
```

The command speaks ACP over stdin/stdout and writes diagnostics to stderr.

```sh
acp-go-opencode -cwd /workspace/project -pure
```

## Embedded Go

Use `Serve` when another Go application already owns the ACP streams:

```go
err := opencodeacp.Serve(ctx, input, output,
    opencodeacp.WithCwd("/workspace/project"),
    opencodeacp.WithPure(true),
    opencodeacp.WithHostname("127.0.0.1"),
    opencodeacp.WithPort(0),
)
```

The wrapper starts `opencode acp` behind a narrow JSON-RPC proxy. Native OpenCode
ACP methods pass through unchanged; wrapper-owned `_opencode/session/*`
extension methods are handled by the proxy and advertised in `initialize`
metadata.

When `input` is not an `*os.File`, `Serve` copies it to the child through a
pipe. Embedders should pass a reader that eventually returns data or EOF so
shutdown can finish cleanly.
