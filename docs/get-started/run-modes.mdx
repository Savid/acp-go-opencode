# Run Modes

## Command

`acp-go-opencode` is intended to be launched by an ACP client.

```sh
acp-go-opencode -path /usr/bin/opencode -home /tmp/acp-opencode
```

## Embedded

```go
agent := opencodeacp.NewAgent(opencodeacp.WithHome(home))
```

or:

```go
err := opencodeacp.Serve(ctx, input, output, opencodeacp.WithHome(home))
```
