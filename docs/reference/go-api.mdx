# Go API

Primary entry points:

```go
agent := opencodeacp.NewAgent()
err := opencodeacp.Serve(ctx, input, output)
```

Common options include `WithExecutablePath`, `WithHome`, `WithDefaultModel`,
`WithEnv`, OpenTelemetry provider options, `WithSessionStore`, and
`WithConcurrencyLimits`.

OpenCode options include `WithOpenCodePure`, `WithOpenCodeQuestionTool`,
`WithOpenCodeLogLevel`, `WithOpenCodeMinimumVersion`, and
`WithOpenCodeHealthCheckTimeout`.
