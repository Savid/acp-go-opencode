# Metadata

Lifecycle requests accept:

```json
{
  "_meta": {
    "opencode": {
      "options": {
        "model": "provider/model",
        "env": {},
        "mode": "build",
        "permission": "ask"
      },
      "rawEvent": {
        "enabled": false
      }
    }
  }
}
```

Unknown keys under `_meta.opencode` are rejected. Foreign namespaces are
ignored.

`_meta.opencode.options.permission` accepts `ask` or `allow`. Empty is treated
as `ask`. The adapter writes the value into the isolated per-session OpenCode
config as `permission: {"*": "<value>"}` before starting `opencode serve`.
