---
title: Metadata
description: The _meta.opencode vocabulary on requests, responses, and error payloads.
---

The adapter carries its non-standard surface under the `_meta.opencode`
namespace. Unknown keys under `_meta.opencode` are rejected; foreign top-level
namespaces are ignored. Malformed `_meta` — a non-object `_meta.opencode`
namespace, an unknown key, or a wrong-typed known option value — is rejected
with an invalid-params error (`-32602`); unsupported keys and wrong-typed
values carry the uniform `{"error": "unsupported", "field": "<path>"}` data.

## Request input

Lifecycle requests accept:

```json
{
  "_meta": {
    "opencode": {
      "options": {
        "model": "provider/model",
        "env": {},
        "mode": "build",
        "permission": "ask",
        "outputSchema": {}
      },
      "rawEvent": {
        "enabled": false
      }
    }
  }
}
```

| Key | Values |
|---|---|
| `options.model` | `provider/model` string. |
| `options.env` | Environment overrides for the native process. |
| `options.mode` | An enumerable OpenCode agent name. |
| `options.permission` | `ask` or `allow`; empty is treated as `ask`. |
| `options.outputSchema` | JSON Schema object for native structured output. |
| `rawEvent.enabled` | Opt in to `_opencode/rawEvent` notifications. |

`_meta.opencode.options.permission` is written into the isolated per-session
OpenCode config as `permission: {"*": "<value>"}` before `opencode serve`
starts.

## Response output

| Path | Meaning |
|---|---|
| `_meta.opencode.structuredOutput` | Validated structured-output result on the prompt response. |
| `_meta.opencode.messageId` | Native message id on `usage_update` notifications. |

## Advertised capabilities

The initialize response advertises adapter surfaces under
`_meta.opencode`: `fork`, `elicitation`, `rawEvent` (method, enable path, and
`maxBytes`), `sessionStore` (format and key), and `structuredOutput` (config
path, result path, and schema mode).

## Turn-failure error data

A failed turn returns an ACP internal error whose `data` carries:

| Field | Meaning |
|---|---|
| `error` | Always `opencode_turn_failed`. |
| `cause` | `provider`, `transport`, or `timeout`. |
| `message` | The real native cause text. |
| `statusCode` / `providerCode` | Included when the provider reports them. |
| `structuredOutputRequested` | `true` when the turn sent a native output schema. |
