# Overview

`acp-go-opencode` exposes OpenCode as an embeddable ACP agent. The adapter
creates one loopback `opencode serve` process per ACP session and talks to it
through authenticated REST and SSE.

The package provides:

- ACP `Serve` and `Agent` APIs
- isolated per-session XDG data, config, cache, and state directories
- native OpenCode message replay for `session/load`
- `session/resume` without replay
- `session/delete` with store tombstones
- `_opencode/session/fork`
- `_opencode/rawEvent` after per-session opt-in
- `opencode-state-v1` session storage
